## Installation

The development version can be installed from
[GitHub](https://github.com/shah-in-boots/recast). Once `{recast}` is
accepted on CRAN, it can be installed from CRAN as well.

``` r
# Development version
remotes::install_github("shah-in-boots/recast")
# CRAN installation after release
install.packages("recast")
```
